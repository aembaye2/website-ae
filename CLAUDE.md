# Abel Embaye — Academic Website

This is Abel Embaye's academic website, built with [Quarto](https://quarto.org/) from the
[Quarto Academic Website Template](https://github.com/drganghe/quarto-academic-website-template)
(originally by Dr. Gang He). It renders to static HTML and is deployed to
`https://aembaye.hosted.uark.edu/` — a UARK-hosted web space, **not GitHub Pages**.

Repo: https://github.com/aembaye2/quarto-academic-website-ae

## How the site is edited

Quarto builds HTML pages from `.qmd` (Quarto Markdown) files and `.yml` data files. Edit the
source files below — never hand-edit anything inside `docs/`, since that whole folder is
regenerated by `quarto render` and any manual changes there are lost on the next render.

| To change...                      | Edit this |
|---|---|
| Site title, navbar, footer, social links, analytics | `_quarto.yml` |
| Home page bio, photo, experience/education lists     | `index.qmd` |
| Contact info (email, phone, office, hours)           | `contact.qmd` |
| Teaching page                                        | `teaching.qmd` |
| Grants/projects list                                 | `projects.yml` (rendered by `projects.qmd`) |
| News / events / selected papers                      | `posts/` (one folder per post) and `posts/post-links.yml` for external links |
| Publications (auto list)                              | `publications.xlsx` — fill in rows; **do not** hand-edit `publications.yml`, it's regenerated from the Excel file on every render |
| Publications (manually curated page)                  | `publications.qmd` |
| Headshot / site images                                | `files/images/` |
| CV / biosketch PDF                                    | `files/nsf-biosketch.pdf` (replace with your own, keep the filename or update the link in `_quarto.yml`) |
| Global site CSS                                       | `styles.css`, `custom.css` |

Site is currently configured as a **solo academic page** — the "Group"/People navbar item
(`people.qmd`, `/people/*.yml`) is template scaffolding for a lab/group site and isn't
part of Abel's active content.

## How to render locally

Requirements (one-time setup):
- [Quarto](https://quarto.org/docs/get-started/) — already installed (`quarto --version`)
- Python 3 with `openpyxl` (and optionally `pyyaml`) — needed because `_quarto.yml` runs
  `python xlsx_to_yml.py` as a `pre-render` step to convert `publications.xlsx` into
  `publications.yml`:
  ```
  python -m pip install openpyxl pyyaml
  ```

Render the full site:
```
quarto render
```
This writes static HTML to `docs/` (the `project.output-dir` set in `_quarto.yml`).

Live-reload preview while editing:
```
quarto preview
```

### Known quirks
- `website.image` in `_quarto.yml` must be a **local file path**, not a remote URL. A remote
  URL there crashes Quarto's RSS-feed generator on Windows (`stat` fails on a URL). It's
  currently set to `files/images/headshot.jpg`.
- `quarto render` prints "unclosed div" warnings while building `pub-listing.qmd`. These come
  from the EJS-generated publication listing and are cleaned up automatically by
  `remove-stray-divfence.lua` (registered as a filter) — the final HTML has no stray `:::`.
  Harmless; no action needed.

## How it's deployed

The site is **pure static HTML/CSS/JS** — no server-side code, no database. Deployment is just
copying the contents of `docs/` to the web root of the UARK hosted space:

1. Run `quarto render` to regenerate `docs/` from the latest source.
2. Copy the **contents** of `docs/` (not the `docs` folder itself) into the web root on the
   mapped UARK network drive for `aembaye.hosted.uark.edu` (e.g. the `public_html` folder, or
   whatever directory the drive maps to — confirm this once with UARK IT if unsure).
3. Overwrite existing files so stale pages don't linger.
4. Visit https://aembaye.hosted.uark.edu/ and spot-check a few pages.

This repo also tracks `docs/` in git (not `.gitignore`d) and has a GitHub remote
(`aembaye2/quarto-academic-website-ae`) for version history/backup — but GitHub Pages is
**not** the publishing target here, UARK hosting is.
